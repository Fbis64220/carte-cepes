# Carte à cèpes

Carte des zones les plus favorables à la pousse des cèpes, calculée à partir de :
- la météo des 45 derniers jours et des 7 prochains (Open-Meteo, modèles Météo-France) ;
- le relief (RGE ALTI, IGN) ;
- les essences forestières (BD Forêt V2, IGN).

Ouvrir `index.html` dans un navigateur, ou la version en ligne via GitHub Pages.
France métropolitaine uniquement. Modèle empirique d'aide à la décision : respectez la propriété privée et la réglementation locale de cueillette.
